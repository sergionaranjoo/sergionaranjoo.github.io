PARA QUÉ SIRVE

Entender por qué llaman los clientes y qué mejorar

Este dashboard reúne las llamadas a atención al cliente sobre la aplicación: fallos, dudas de uso y necesidades relacionadas con el producto. Cada llamada registrada se muestra como una consulta y se clasifica en una categoría según su motivo.

Sirve para identificar los problemas más frecuentes, detectar aumentos de llamadas y priorizar mejoras del producto. Los filtros permiten descubrir si un problema se concentra en un tipo de cliente, equipo o periodo.

En el producto original, la actualización recupera los registros de la base de datos. Aquí puedes explorar el mismo flujo con un escenario ficticio.

Guía rápida · qué puedes explorar

El problema: cuando llegan consultas sobre un producto, contar mensajes no basta. Este panel ayuda a descubrir qué problemas se repiten, a qué clientes afectan y cómo cambian con el tiempo.

  1. Elige Aplicación o Cámaras. Son dos productos de ejemplo, con consultas y clientes diferentes.
  2. Abre Filtros. Acota por fecha, tipo de cliente, motivo o características del producto. Pulsa Limpiar filtros para volver al conjunto completo.
  3. Explora las gráficas. Las barras separan las consultas por motivo. Pasa el cursor para ver cifras; también puedes elegir un motivo en la tabla para filtrar.
  4. Compara con contexto. La vista de consultas por cliente tiene en cuenta cuántos clientes hay. La comparativa anual alinea la misma semana o mes de dos años.
  5. Prueba la comparación de versiones. Puedes excluir una consulta de ejemplo y ver cómo cambia la gráfica. La selección se guarda solo en este navegador si permite almacenamiento.

Cómo leer las cifras: 20 consultas entre 1.000 clientes equivalen a 2 consultas por cada 100 clientes (2 %). Un cliente puede realizar varias consultas; esto no significa que el 2 % de los clientes haya contactado.

Qué demuestra el producto: navegación por productos, filtros combinables, clasificación de consultas, comparativas temporales y exportación. Las cifras simuladas no representan resultados de ninguna empresa ni prueban que una versión sea mejor.

Escenario simulado hasta el 25/10/2026. Octubre de 2026 está incompleto; compáralo con precaución con meses completos.
