PARA QUÉ SIRVE

Evaluar un producto nuevo antes de lanzarlo

Este dashboard compara las llamadas a atención al cliente del producto actual con las del producto que se está probando en una prueba piloto: un lanzamiento limitado a un grupo de clientes antes de extenderlo al resto.

Sirve para detectar si aparecen más fallos, dudas o necesidades durante la prueba y decidir qué investigar o mejorar antes del lanzamiento. La gráfica compara llamadas registradas por cada 100 clientes, porque los dos grupos tienen tamaños diferentes.

Nueva: producto en prueba pilotoActual: producto que ya utilizan los clientes

Cada caso o consulta representa una llamada registrada. Una diferencia entre grupos es una señal para investigar; por sí sola no demuestra que la nueva versión sea la causa.

Guía rápida · cómo interpretar el piloto
  1. Compara las dos líneas. Nueva representa el producto en prueba; Actual, el producto que ya se utiliza.
  2. Elige semanas o meses. La frecuencia agrupa las llamadas en periodos diferentes. Mostrar limita los periodos visibles en la gráfica.
  3. Comprueba el tamaño de cada grupo. La tasa divide las llamadas del periodo entre los clientes de esa versión. Así puedes comparar grupos de tamaños distintos.
  4. Revisa las consultas del piloto. Si una llamada no está relacionada con el producto que se está evaluando, puedes desmarcarla para excluirla del análisis. Los clientes del grupo se mantienen.
  5. Actualiza o exporta. En el producto original, Actualizar datos consulta la base de datos. Esta muestra solo recalcula el ejemplo. El CSV permite revisar las cifras por periodo.

Todos los registros y comentarios de esta muestrastración son inventados.
